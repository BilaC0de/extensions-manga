# Extensions Manga — BilaC0de

Dépôt de distribution des extensions Mihon développées et maintenues personnellement.

## Ajouter le dépôt dans Mihon

1. Ouvrir Mihon → **Paramètres** → **Sources** → **Dépôts d'extensions**
2. Ajouter l'URL suivante :

```
https://raw.githubusercontent.com/BilaC0de/extensions-manga/repo-manga/index.min.json
```

## Sources disponibles

Les extensions sont principalement orientées vers les sites de scanlation francophones.

## Informations techniques

| Build | GitHub Actions sur push `dev` |

## Développement

Le code source des extensions se trouve dans le dépôt [mangas-extensions-source](https://github.com/BilaC0de/mangas-extensions-source).

Les extensions sont compilées et publiées automatiquement à chaque push sur la branche `dev`.
